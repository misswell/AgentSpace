# 0.1.42 — 桌面窗口恢复点击，并如实显示 Retina 像素

**在 AgentSpace 中按「检查更新」安装这一版。** 已发布的 0.1.41 无法覆盖，本版是新的补丁发布。

「打开桌面」现在每三秒轻量刷新正在查看的 Agent 账号状态。后台会话从休眠恢复或 Worker 重启后，窗口会重新启用输入，不需要关闭重开。快速输入通道收到成功回执后也会清除旧的拒绝提示，避免已经恢复的点击仍显示成失败。

切换缩放时，采集请求不再超过 Agent 桌面的真实源像素。以前 200% 可能向 1920×1080 的 1× 桌面请求 3840×2160 缓冲区；那只是放大已有像素，还会增加重连与共享内存压力。窗口底部现在分别显示画面像素、Agent 桌面的逻辑点数、实际像素和倍率。

当前 AgentUse 主屏由 macOS 报告为 1920×1080 点、1920×1080 像素（1×），内建屏报告为 1512×982 点、3024×1964 像素（2×）。本版继续查看原来的主屏；不会把 1× 内容伪报成 Retina，也不会创建会影响主系统显示布局的虚拟屏。

本地 Swift 测试、MCP、更新器和独立 Agent 会话界面门禁通过。托管 CI 无法操作真实 Aqua 桌面；安装后仍需人工确认缩放切换后的点击。
