# 0.1.45 — Worker 更新现在能替换任何残留的 Worker 进程

本版第一句话是给刚从 0.1.44 升级的人的:**App 和 Worker 本身的行为与 0.1.44
完全一致,点击修复都在 0.1.44 里已经生效;本版只加固更新流程本身。**

修复的问题:Worker 更新是「换文件 → launchd 重启进程」。如果有一个不受
launchd 管理的 Worker 进程还在运行(崩溃恢复、手动启动都可能造成),它会一直
占着运行时锁——文件换好了,launchd 拉起的新进程启动即退出,旧进程继续用旧版本
应答,App 就一直报「Worker 版本不匹配」。0.1.44 发布当天,这台 Mac 上实测
复现了这个状态(§336 row 968)。

现在 helper 在重启 Worker 前会终结该账号名下、仍残留在自己安装路径里的
Worker 进程,再由 launchd 启动新版本。扫描范围刻意收窄:只匹配该账号的
uid、且命令行位于 helper 自己的 Worker 安装路径之下。

**本版需要「重新安装助手…」让 root 助手同步到 0.1.45,macOS 会要求管理员
授权——这次会看到密码提示。** Worker 会随后台刷新自动跟进。

本地单元测试、MCP、更新器与 Agent 会话界面检查通过。正式包由 CI 签名、
公证并发布。
