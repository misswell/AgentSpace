# 0.1.86 — 「把 MCP 安装到…」认识 24 个客户端，每个都按它自己读的格式写入

更新 AgentSpace 到 0.1.86。**需要你做的事**：

1. 安装 0.1.86。这一版改的是 App 和随包的 `agentspace` CLI；Worker、helper 和 MCP 服务的协议没有变，已连接的账号和桌面不需要重新登录。
2. 用哪个客户端，就在账号页的「维护」卡片里打开「把 MCP 安装到…」并选中它，或者运行 `agentspace integrate <target> --install`，然后重启那个客户端。菜单按「命令行 Agent / 编辑器 / 桌面应用 / 编辑器扩展」分组，共 **24 个客户端**，另有一个「其他 MCP 客户端」复制入口。拿不准 target 名字时，`agentspace integrate` 不带任何参数就会列出全部 24 个、显示名和各自写入的文件（退出码 0；加 `--json` 机器可读）。
3. 如果你之前已经给 Claude Code、Codex、OpenCode、ZCode、Kimi Code 或 Xiaomi MiMo 装过 AgentSpace 的配置，**不需要重做**：这六家的路径和格式没有变，重跑也只是覆盖 AgentSpace 自己那一条。新支持的 18 家才需要你选一次。

**新增的客户端。** 命令行 Agent 15 个：Claude Code、Codex、OpenCode、ZCode、Kimi Code、Xiaomi MiMo、Gemini CLI、Qwen Code、Qoder CLI、Amazon Q Developer、GitHub Copilot CLI、Crush、Amp、Factory Droid、MiniMax Code。编辑器 6 个：Cursor、Windsurf、VS Code（Copilot）、Zed、Kiro、Antigravity。桌面应用 2 个：Claude Desktop、LM Studio。编辑器扩展 1 个：Cline。另有「其他 MCP 客户端」：打印一段通用 `mcpServers` 配置供你粘贴，或由 `agentspace integrate generic --install --config PATH` 合并进你指定的文件。

**每个客户端用它自己的 schema。** 这一版没有用一份「通用 JSON」去套所有客户端，因为错的键有的会被静默忽略、有的会让整条记录失效：VS Code 要 `servers` 加 `type: "stdio"`；Zed 要 `context_servers` 加 `source: "custom"`；Amp 要 `amp.mcpServers`；OpenCode 与小米 MiMo 要 `mcp`、`type: "local"`、把命令和参数放进同一个数组、环境变量键叫 `environment`；ZCode 要嵌套的 `mcp.servers` 且只接受那几个键；Crush 要 `mcp` 加 `type: "stdio"`；MiniMax 要 `mcpServers` 加 `type` 和 `enabled`；Codex 要 TOML 的 `[mcp_servers.agentspace]`。其余客户端接受普通的 `mcpServers`。每个 target 的路径取自该客户端自己的文档；这台 Mac 上已有配置文件的 11 个 target，位置也逐一核对过。

**写入仍然只碰它自己那一条。** 安装器只改 AgentSpace 拥有的那个键，文件里的其他服务器、`$schema`、`plugins` 等原样保留；第一次改写已有文件之前会先存一份 `<文件>.agentspace.bak`。Codex 里若已有一段不是本工具生成的 `[mcp_servers.agentspace]`，会拒绝而不是覆盖。配置文件里带 `//` 注释时（例如 VS Code、Zed、MiMo 的 `.jsonc`），写入会停下来并让你用手工方式合并——重写会删掉你的注释，所以宁可不写。生成的配置里，二进制路径只出现在 `AGENTSPACE_BIN` 中，不会作为参数写死；它启动的就是这个 App 自带的 MCP 服务。

**没有变的部分。** MCP 服务的工具集合与协议不变，账号、Worker、helper、桌面驱动和权限流程都不变；这一版只扩展了「把已有的 MCP 服务接进哪个客户端」这一步。客户端仍然必须在它自己的会话里得到 `agentspace_*` 工具；AgentSpace 不会为了「看起来连上了」去驱动你的主会话，也不新增任何绕过 `SESSION_IS_CONSOLE` 的路径。

**顺手修正的说明文字。** 账号页空状态原来写「Install MCP Into… above」，但那个菜单在下方「维护」卡片里；现在改为「menu on this page」，中英文两处同步。
