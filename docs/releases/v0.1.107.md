# AgentSpace 0.1.107

**本版只改设置窗口的两个标签标题,不需要你做任何事;「更新后首次使用」仍会出现一次标准的 Worker/助手版本对齐提示,照常允许即可。**

---

## 这一版改了什么

- **设置窗口的「Virtual Network」和「Update」两个标签标题完成中文化**:中文系统现在显示「虚拟网络」和「更新」,与「通用」「高级」等其他标签一致;英文系统显示不变。此前这两个标题是界面上仅有的两处未经本地化的文字,在中文界面里直接以英文原文出现。

## 测试

两个标题的 key 进入中英两份本地化表,`LocalizationTests` 一致性门与全套 Swift 测试(**1058 项、0 失败**)通过;标签顺序未动,基于按钮序号的界面验证脚本不受影响。
