# 0.1.82 — MCP 补齐桌面和系统操作入口

先更新 AgentSpace 到 0.1.82；本次 **Worker 有新增能力**，如出现版本不一致提示，请用应用现有的「重新安装助手…」入口更新。再运行一次「Install MCP Into…」或 `agentspace integrate <client> --install`，并重启对应 Agent 客户端，让它重新加载工具列表。客户端仍需 Node.js 18 或更新版本，推荐 22。

这次把已存在却没有接到 MCP 的系统能力接通，也补了日常操作缺口：

- 查询已安装应用、激活应用、移动鼠标和读取焦点控件。
- 根据 AX 角色、标题或标识执行菜单与控件动作；给唯一匹配且可写的文本框、滑块等控件设置值。
- 获取窗口身份，激活、关闭、最小化、移动和调整大小；过期窗口身份会被拒绝。
- 在 Agent 桌面打开网页、本地文件/目录和系统设置 URL。
- 读写 Agent 账号自己的文本剪贴板；空文本清空，最大 1 MiB。
- `agent_capabilities` 说明各类操作的使用流程、权限和边界。全部工具统一提供 `agent_*` 与 `agentspace_*` 两种名称，共享同一实现。

AX 搜索会对控件身份去重，避免重复节点或循环关系耗尽搜索预算。已在后台账号实测控件值写入读回，以及窗口调整、最小化、恢复、激活与关闭。最小化后窗口可能从窗口列表消失，需要用 `ax_perform` 对指定窗口执行 `AXRaise`，再重新列出窗口获取新身份。macOS 会话若发生 AX 异常、缺少可用控件或 frame，相关动作会明确拒绝；验证记录保留了异常和恢复后两次实测。

**安装包也能直接接入 MCP。** 过去自动配置使用 `npx @agentspace/mcp`，但该包尚未发布到 npm。现在 App 随包携带本版 MCP 服务与生产依赖，集成配置优先运行当前安装的服务，连接时无需下载这个包。已由 AgentSpace 生成的旧 Codex 配置会按精确匹配迁移；其他自定义配置沿用原有保护与备份。

**缩小截图后不会再按错位置。** 截图结果直接给出这张图片的坐标换算系数，包含下采样比例和显示器原点；显示器编号统一从 1 开始。

覆盖目标是标准 Agent 账号内的日常 macOS 操作。管理员批准、登录解锁、密码提示和隐私权限授权仍由人在 macOS 中完成；部分自绘控件需要鼠标键盘操作，剪贴板目前只支持文本。具体覆盖与剩余缺口见 [MCP system feature coverage](../MCP_SYSTEM_FEATURES.md)，验证证据见 validation §383。
