# 0.1.71 — 无产品变更：宣传动画视频素材

已安装的用户**什么都不用做**；本版不改变 App、Worker、CLI 或 MCP 的任何行为，
没有需要按下的按钮，也不需要重装助手。

本轮唯一的内容是市场素材：`marketing/promo/` 下新增一段 38 秒的产品宣传动画
（1080p 横版与 9:16 竖版，H.264，无声），以及它的可复现源工程
（`promo.html` + `render.mjs`，无头 Chrome 逐帧渲染、ffmpeg 合成）。动画使用的
是仓库内的真实应用图标，文案口径与 README 一致，全程不出现二维码，下载地址
只以文字 `github.com/misswell/AgentSpace` 呈现。

产品代码仅按惯例随版升了四处版本号字符串（Info.plist、CLI、Core、Diagnostics），
无任何逻辑改动。证据见 `docs/validation.md` §371。
