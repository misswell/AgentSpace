# AgentSpace 0.1.105

**本版移除了端口映射与账号固定地址。更新不需要你做任何事;已建的映射停止服务,`lo0` 上若残留固定地址会在应用启动时自动移除;「更新后首次使用」仍会出现一次标准的 Worker/助手版本对齐提示,照常允许即可。**

---

## 为什么移除

实测把两件事钉死了(macOS 全机一个内核网络栈、一张端口表):

- **主系统本来就能直接访问子账号的端口**——所有账号共享同一回环网络,子账号监听的 `127.0.0.1:<端口>`,主系统用同一个端口号直接调用即可,转发从来不是为了「能不能通」;
- **两个账号不可能各用同一个端口**——第二个绑定者被内核直接拒绝(errno 48),而写死绑 `127.0.0.1` 的服务(如 magpie 网关)永远不会迁到给账号分配的 127.100.x.y 地址上,固定地址给不了它承诺的东西。

## 保留的部分

- 账号页新增「**监听端口**」卡片:该账号自己的进程正在监听哪些 TCP 端口(进程名 + 绑定地址),每几秒自动刷新;
- CLI `agentspace ports <账号>` 输出同一份清单;
- 每一行主系统都能直接以 `127.0.0.1:同端口号` 访问——无需映射。

## 兼容

`map` / `unmap` / `address` 子命令现在返回一句说明(不再是映射操作);worker 协议 `ports.list` 原样保留,旧版 CLI 不受影响;帮手封闭操作列表不变(13 项)。

## 测试

全套 Swift 测试 **1050 项、0 失败**(移除 24 项端口映射专属用例);真机验证:清单含 3426(magpie 网关)与 rapportd 三项,移除说明与无账号模式行为正确。
