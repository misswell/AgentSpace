# 0.1.55 — 切进账号就能看到授权弹窗：worker 启动即请求

通过「检查更新」更新 App,然后按一次「**重新安装助手…**」——本回合的修复在 **worker** 里,不换 worker 不生效。已连接的账号换完助手后,worker 会重启一次;此时切进账号会话,授权弹窗就等着你。

## 这次解决什么

实测报告:切到新连接账号的会话里,系统设置里**找不到 agentspace-worker,也没有任何弹窗**。原因:macOS 只会把「主动请求过」的进程列进隐私列表并弹提示,而此前 worker 只有无提示的预检,发起请求的调用只藏在 App 的授权按钮后面——按钮没按过,列表就是空的,而且 TCC 的「+」选择器不接受裸二进制,用户手动加也加不进去。这是个死路。

现在的行为:**worker 启动时,若两项授权有缺失,立即代自己向 macOS 发起请求**(辅助功能带提示调用 + 屏幕录制请求)。于是:

- 换完助手、worker 起来之后,切进账号会话,授权弹窗已经在那里等;
- 就算错过弹窗,系统设置的辅助功能/屏幕录制列表里**会出现 agentspace-worker 条目**,开关打开即可;
- 已授权的账号启动时只做两次预检,不碰任何请求;测试环境(覆盖 root)完全豁免,不会在自动化里弹窗。

授权向导里也补了一句说明:列表为空 = 还没人请求过,按「打开设置」会一步完成请求和打开面板。

验证记录见 `docs/validation.md` §347。
