# 0.1.50 — 浮窗开关解耦与移动投递自愈

通过「检查更新」或重新安装更新本 App，无需任何设置更改。若桌面查看器再次出现「接管状态但指针不跟随」或整窗点击无响应：退出并重新打开 AgentSpace 即可恢复，并把当时的操作告诉我们，以便定位触发条件。

- **性能浮窗开关解耦**：开关浮窗不再触发整个查看器重建。此前开关写入的偏好由整个 `DesktopViewerView` 读取，翻转一次会让承载实时画面的视图、捕获协调器与光标覆盖层全部重算；现在只有浮窗与详情弹层里的开关行各自观察该偏好，查看器主体不再读取它。
- **移动投递自愈**：macOS 在菜单或浮窗接管指针跟踪期间会关闭窗口的鼠标移动事件投递；本系统上浮窗关闭后该投递可能停留在关闭状态——表现为「已接管（本地光标隐藏）但指针不跟随，点击仍然有效」。现在进入画面、点击、布局刷新与光标矩形刷新都会重新打开该投递，无需重建窗口。

两起现场报告（上午整窗点击无响应、下午接管不跟随）均未在开发机上复现；修复依据是症状与机制的吻合，实际手感以人工验收为准。验证结果记录于 `docs/validation.md` §342。
