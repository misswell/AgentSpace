# 0.1.67 — 仪表盘状态真的自动刷新了：「状态刷新」滑块从死设置变成真轮询

先「检查更新」。本版只改 App，Worker 无需重装助手。

修复的问题：设置里的「状态刷新」滑块（2–10 秒，默认 3 秒）从第一个版本起就没有接到任何轮询上——面板只在启动、切回前台或按 ⌘R 时刷新，Worker 掉线/上线、权限变化都要手动刷新才能看见。

现在：

- 主窗口按滑块设定的间隔自动刷新每个账号的状态（默认 3 秒）。掉线的 Worker 恢复后，横幅和概览会在一个间隔内自己消失；反之亦然。
- 间隔改动立即生效（下一个 tick 采用），无需重启。最小 2 秒是计划 §53 的硬下限，默认值外的 `defaults write` 也会被钳制。
- 自动 tick 保持轻量：每个账号一次 status RPC，不做磁盘测量、助手检查和版本修复——这些仍由前台激活和手动刷新触发。
- 关闭主窗口即停止轮询；重开窗口恢复。

实测对照（AgentUse 会话内，不打扰本人屏幕）：0.1.65 启动后 20 秒内零次状态请求；本版默认间隔严格 ~3.1 秒一次、设为 5 秒时严格 ~5.2 秒一次。设置页的滑块下新增了一行说明，写明它驱动的是什么。

验证证据见 `docs/validation.md` §367。
