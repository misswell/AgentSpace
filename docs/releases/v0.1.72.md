# 0.1.72 — 在主桌面登录 Agent 账号

更新 AgentSpace 后，在“系统设置 → 通用 → 共享”开启**屏幕共享**，将允许访问设为
**仅这些用户**并加入 Agent 账号。无需改密码，也无需修改账号或隐私数据库。
已安装用户可使用“检查更新”；助手仍须已安装并可用。更新后的版本检查会通过
既有助手路径更新 Worker，若 macOS 要求管理员确认，请完成授权。

未登录或已锁定的账号页面新增**登录 / 解锁 Agent**。点击“打开 macOS 登录窗口”，在系统窗口中
输入 Agent 账号自己的密码。若系统询问，请选择**以本人身份登录：Agent 账号**，
并使用**标准**屏幕共享。在该窗口中完成首次登录设置。AgentSpace 检测到对应的
桌面会话后自动完成 Worker 安装和启动，无需切换主账号屏幕。已有 Worker 的账号
会等待 Agent 自己的桌面解锁后才显示已连接；解锁主账号不会解锁 Agent 桌面。
已锁定的 Agent 在侧栏、账号卡片和桌面详情中显示“已锁定”，不会继续标为“就绪”。

登录完成后，关闭临时的屏幕共享窗口，再点击“完成”。之后继续使用 AgentSpace
的“打开桌面”和权限授权按钮。快速用户切换登录方式仍然可用。

密码由 macOS 自带的屏幕共享应用处理，AgentSpace 不读取或保存密码；本版不提供
无人值守输入密码或绕过认证。临时转发连接只监听本机地址，取消、关闭对话框、
失败或超时均会收尾；关闭连接不会主动注销 Agent 账号。登录是否成功以目标
账号的图形会话和 Worker 的后台会话状态为准，控制台和未知会话继续拒绝输入。

实现与验证见 `docs/validation.md` §372。

同时修复输入连接断开时可能导致 App 或 Worker 被 SIGPIPE 终止的问题。连接关闭
现在进入既有断线处理，不会终止进程；这是 App 与 Worker 共同使用的输入通道修复。
