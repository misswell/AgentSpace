# 0.1.48 — 桌面操作与画面跟手优化

**在 AgentSpace 中检查更新并安装新版 App。若出现助手版本更新提示，按提示完成管理员授权。**

此版本也包含尚未公开发布的桌面预览布局调整：移除底部两行控制区，将重连、预览、缩放、画质、帧率、鼠标接管、快照和信息入口集中在一行顶栏，让画面使用更多窗口高度。

桌面预览会先在本地绘制鼠标位置，再根据 Agent 桌面回报的位置做小幅校正；光标形状仍由 Agent 桌面提供。鼠标移动速率跟随当前显示器，桌面和 Fusion 窗口会在空闲时降低采集帧率，在拖动或滚动时提高到 60 FPS。画面渲染改为直接使用 Metal 着色器，并保留等比缩放。

桌面预览顶栏的信息菜单新增可选的性能浮层，可查看画面帧率、鼠标移动与其他输入从发送到 Worker 投递的 p50/p95，以及画面采集到显示的延迟。这些数值用于定位问题；目前没有证据表明所有机器或所有窗口数量都能达到固定延迟或 CPU 阈值。

Fusion 窗口继续使用 macOS 原生拖动、调整大小、最小化和全屏行为；本次还让焦点窗口在静止时降到 5 FPS，发生内容变化时回到 30 FPS。多个同时打开的预览各自消耗采集与渲染资源。
