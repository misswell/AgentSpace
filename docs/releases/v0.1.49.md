# 0.1.49 — 三种鼠标控制模式

安装或通过「检查更新」更新 App 后，在桌面查看器顶部选择「自动」「接管」或「点击后接管」。本次鼠标控制逻辑在 App 内；若版本检查提示更新 Worker，按现有管理员提示完成更新。

- **自动**：外层鼠标停稳 200 毫秒后，同步到远端对应位置并触发 hover；移动途中不持续控制远端鼠标。点击和拖动立即响应。
- **接管**：鼠标进入远端画面后持续跟随外层鼠标，离开画面交还控制。
- **点击后接管**：保留现有按下期间接管、松开后交还的行为。

三种模式同时应用于 Desktop Viewer 和 Fusion。旧「关闭」偏好迁移为「点击后接管」。Control-Option 或 Control-Command-G 仍可交还控制。鼠标离开、模式切换、输入不可用或窗口关闭会取消待执行的自动 hover。

验证结果记录于 `docs/validation.md` §341；独立账户内的管理界面检查不代表人工验收了三种模式的实际操作手感。
