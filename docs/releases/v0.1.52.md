# 0.1.52 — 主窗口去重：工具栏不再重复页面里已有的按钮

通过「检查更新」更新 App 即可。本次改动只在 App 的管理界面；Worker 与协议未动，不需要「重新安装助手」。

- **工具栏去掉两个重复菜单**。「授权」盾牌菜单的三项（打开辅助功能设置、打开屏幕录制设置、打开授权向导）本来就在「权限与授权」卡片里；「Agent」齿轮菜单的「断开账号连接…」本来就在「维护」卡片里。工具栏现在是一组直接动作：打开桌面、打开 App 窗口、在 Agent 中启动…、应用、刷新。
- **「停止 Agent」移到「维护」卡片**（原来只在齿轮菜单里），旁边就是「断开账号连接…」。悬停说明写清楚：只停该账号的后台 Worker，macOS 会话保持登录。
- **一页只有一个「刷新」**。页头的「刷新」和权限卡里的「刷新授权状态」跑的是同一个完整重载，现在统一为工具栏的一个刷新按钮（菜单 ⌘R 不变）。页头的大标题整体删除——名称在工具栏标题和侧栏里，状态成为「概览」卡第一行。
- **概览卡不再把三项权限胶囊印两遍**——紧挨着下面就是「权限与授权」卡。「显示器」的三行几何数据并入概览卡，页面少一张卡、少一屏滚动。

界面行为没有任何删除：原菜单里的每一项都还在页面上原来的位置。验证记录见 `docs/validation.md` §344。
