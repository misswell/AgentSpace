# 0.1.60 — 首次打开桌面窗口立即出画面

**这次只改了 App：通过「检查更新」更新即可，不需要「重新安装助手…」。**

你报告的现象：桌面窗口首次打开一直停在「正在抓取 Agent 的桌面…」，点一下 ▶ 才出画面。原因是一个启动竞态：窗口出现的瞬间，该账号的状态快照往往还没把「显示器信息」取回来（查看器每 3 秒刷新一次状态），而开流的第一个前置条件就是它——守卫静默失败之后，**没有任何路径在信息到达后补启动**；你按 ▶ 的那一刻信息早已就位，所以一按就好。

- 现在：显示器报告和 worker 上线这两个状态一到达，窗口就自动补启动流——打开即出画面，不用再按 ▶。
- 你手动按的 ⏸ 仍然算数（这是唯一能让符合条件的窗口保持黑屏的理由），再按 ▶ 恢复；休眠中的窗口也不会被自动唤醒，点击唤醒不变。

验证记录见 `docs/validation.md` §354。
