# 0.1.60 — 「接管」回来了：与「接管隐藏鼠标」并存，不再是改名

通过「检查更新」更新 App 即可。本次只改 App 的鼠标控制模式；Worker 与协议未动，不需要「重新安装助手」。

- **0.1.59 把「接管」改成了「接管隐藏鼠标」，这不是你要的**。现在两个模式都在选择器里：
  - **接管**：指针进入画面即取得控制、持续跟随，但**保留你自己的鼠标光标**——你的光标就是指针，不再额外画一个。
  - **接管隐藏鼠标**（默认，行为与 0.1.59 完全一致）：进入即控制，隐藏你的光标，改画 Agent 会话发布的光标（两侧各一个光标的 RustDesk/Parallels 手感）。
- **自动**（停稳后同步悬停）与**点击后接管**（按住才控制）保持不变。
- **旧选择不会漂移**：之前存过「Capture/接管」的账号，升级后仍解析为「接管隐藏鼠标」——就是 0.1.59 的手感；想要光标可见的，在桌面窗口顶部选择器里选「接管」。

验证记录见 `docs/validation.md` §354。
