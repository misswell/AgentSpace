# 0.1.46 — 远程桌面只有一个屏幕：真实的 2× Retina 主屏

本版第一句话是给正在用桌面预览的人的:**打开桌面预览后,远程桌面现在只有一块
屏——会话里那块真实 2× Retina 屏(1512×982 点 / 3024×1964 像素)临时成为主屏,
Dock 和菜单栏都在它上面;预览关闭时恢复你原来的排列。** 之前预览固定选副屏,
看不到只显示在主屏的 Dock。

同时修复点击变双击:点击菜单/按钮后立即收起,是「按下已发出、松开时又补发一次
完整点击」。现在按下后即使接管状态在途中变化,松开也只会是抬起,不会变成第二次
点击。

**本版需要两步,而且第二步才是主要部分:「检查更新」带来 App 一半;
「重新安装助手…」带来 Worker 一半(显示器切换在 Worker 里执行)。**
预览打开失败时(如显示器正在休眠或已镜像)会显示原因,重试即可。

不声称的部分:真机 GUI 手势的最终验收(拖动、双指滚动、连击手感)仍需人在
预览前确认;本版的点击证据是单元红绿测试加 Agent 会话内探针实测(down/up
各一次、坐标边界随布局移动)。

本地单元测试、MCP、更新器与 Agent 会话界面检查通过。正式包由 CI 签名、
公证并发布。
