# AgentSpace 0.1.106

**本版给账号页的资源卡片新增「实际新增内存」。更新不需要你做任何事;「更新后首次使用」仍会出现一次标准的 Worker/助手版本对齐提示,照常允许即可——新数字要等 Worker 更新到本版之后才出现,在那之前卡片只显示原有的内存一项。**

---

## 为什么加

原「内存」数字是把该账号所有进程的驻留内存(RSS)相加:全系统共享的库(dyld 缓存、系统框架)物理内存里只有一份,却会被每个进程各计一次,所以那个数偏大——本机实测 5.7 GB 的显示值,真实增量约 4.2 GB。

新增的「**实际新增内存**」按 Apple 自己的口径(`ri_phys_footprint`:每进程私有页 + 已压缩页,按压缩后大小计)对同一批进程求和,更接近「这台电脑为该 Agent 真正多付出了多少内存」。两项并排显示,谁也不替代谁;鼠标悬停说明里写清了区别。

## 细节

- 测量复用状态轮询里已有的进程快照,每个进程一次系统调用,四百个进程不到 1 毫秒,空闲 CPU 不受影响;
- Worker 比本版旧时只显示第一项,不显示伪造的 0;协议是纯新增字段,旧版 GUI/Worker 均不受影响;
- 顺带修复了会话内 UI 校验器的一个盲区:刚启动还没被置前的窗口,辅助功能会读不到——校验器现在会先通过「窗口」菜单把窗口调到前面再判定(本版因此能在忙碌会话里完成全部 19 项界面检查)。
