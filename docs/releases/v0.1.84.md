# 0.1.84 — 首次授权不再需要来回切换用户：屏幕共享入口常驻

更新 AgentSpace 到 0.1.84。**这次没有需要你执行的命令。** 打开任意已连接账号的详情页，「权限与授权」卡片里现在一直有一个屏幕共享入口；点它，在弹出的 macOS 登录窗口里完成认证，然后**让那个窗口保持可见**——之后你从卡片或「授权此 Agent」向导里点的每一项隐私设置，都会出现在那个窗口内，三项授权在这一次进入里全部勾完，不需要在 macOS 用户之间切换。更新后应用会按既有流程把 Worker 与 helper 版本核对到 0.1.84。

**为什么会有这个版本。** 上一轮的反馈说的是体验而不是代码：「首次的权限授权体验很糟糕，需要用户来回切换账号，因为你有三个授权……首先它无法在一次切换中完成，每次都是授权一个」。这个描述里藏着一个真正的缺陷——账号页只在 **Worker 离线或桌面被锁**时才给出屏幕共享入口。也就是说：登录成功的那一刻，入口自己消失了。而那一刻正好是一个人刚勾完第一项、还剩两项要看那个会话的时候。它剩下的唯一选择是快速用户切换，一项授权一次。

更深一层的原因也在这一版说清：隐私面板是由该账号自己的 Worker 在它自己的会话里打开的（§347），所以勾选动作只能在那个会话里看见；而内置桌面查看器需要的正是你正在申请的那项屏幕录制权限。在屏幕录制生效之前，Apple 的屏幕共享窗口是那个桌面**唯一的显示器**。所以旧向导里那句「切换到 %@ 只是为了勾选授权，然后返回这里」，按面板数量算，是一项一次切换。

**入口现在出现在两个地方，且不再消失。** 账号详情页的「权限与授权」卡片，以及「授权此 Agent」向导内部。同一个入口在账号正常时写作「用屏幕共享打开该桌面」，在 Worker 离线或桌面锁定时升级为强调按钮「登录 / 解锁 Agent」——它首先是修复动作，其次才是查看。详情页上「登录」只有一个（概览卡片那份搬到了这里，没有多出第二个同名按钮）。

**向导里的登录是嵌在页面内的，不是再套一层弹窗。** 这不是审美选择：登录控制器停止时会关闭那个回环中继，而中继本身就是屏幕共享的数据通道——收起登录弹窗就等于关掉正在查看的窗口；而一个窗口一次只能呈现一张工作表（§269）。所以向导把登录面板直接嵌进来，并在此后保持打开，让上面三行按钮打开的面板都落在这个窗口里。登录成功后向导不再提供「收起登录面板」，因为那会切断你正在看着的画面。

**这一版没有修好的部分，讲明而不是藏起来。** macOS 一个隐私类别只弹一个面板，产品里的设置面板地址是固定的三条（辅助功能／屏幕录制／全部文件访问），所以三项授权仍然是三次开关；改变的是它们现在发生在**一次进入、不切换用户**的同一个会话里。控制台账号永远看不到这个入口——那个会话就是人自己的屏幕，§3 禁止任何驱动它的路径。关闭向导只结束这次临时查看，Agent 账号仍是登录状态；§376 的屏保与延时解锁组合才是让那个桌面在窗口消失后不自动锁屏的东西。密码始终由人在 macOS 里输入：AgentSpace 不代填、不记录、不写入 TCC 数据库。

验证证据见 validation §385（含层 1 的 858 个测试、层 2 的 19 项更新器检查、层 3 的 MCP 套件与冒烟、层 4 由**会话内**工具执行 17 项全绿；控制台式工具因主人正在使用这台 Mac 而未运行，已如实记录）。
