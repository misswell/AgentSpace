# 0.1.73 — 修复 Worker 更新提示和锁定桌面误显示

请更新 AgentSpace 到 0.1.73。若 Agent 卡片提示 Worker 过期，点击“更新 worker…”后，成功安装当前 Worker 时旧的过期提示会自动关闭；无需重复点击或重新连接账号。

如果 Agent 账号的屏幕仍处于锁定状态，打开桌面现在会明确提示“Agent 桌面已锁定”，而不会把锁屏壁纸显示成可用桌面。请点击“登录 / 解锁 Agent”，在 macOS 系统窗口中解锁 agentuse 账号，再重新打开桌面。

本版没有新增密码输入或绕过 macOS 认证的路径。屏幕共享登录仍由 macOS 处理，Worker 更新仍通过现有特权助手流程完成；若系统要求管理员确认，请完成授权。

CI 会执行第 1–3 层门禁、签名、公证和发布校验。第 4 层需要本机 Console Aqua/TCC 环境，GitHub runner 不执行该层；本机仍应在 Agent 桌面解锁后运行 `scripts/check-all.sh` 复核。
