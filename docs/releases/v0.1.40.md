# 0.1.40 — 修复「打开桌面」里点击没有反应

**在 AgentSpace 中按「检查更新」安装这一版。** 如果 App 发现已连接账号的 Worker 版本不同，会自动从本版 App 包中安装对应的 Worker；macOS 若要求管理员授权，请完成系统提示。更新期间，旧 Worker 的桌面点击也能通过兼容输入路径工作。

现场的 App 是 0.1.39，Worker 仍是 0.1.36。旧 Worker 没有新版 `input.sock`，而「打开桌面」中的鼠标只往这个不存在的通道发送，点击因此被静默丢掉。现在通道未就绪时会使用原有输入 RPC；按下与抬起会合成旧 Worker 能理解的点击或拖拽，滚动和移动也能走旧通道。

还修复了新版通道本身的一个阻塞：它曾在一条串行队列上无限期等待读取回包，新的点击排在后面发不出去。现在读取与发送使用独立队列；连接失败会重试，关闭时会唤醒读取并关闭原连接。

以后位于 `/Applications/AgentSpace.app` 的应用在前台刷新时会读取各账号 Worker 实际运行的版本。发现版本不一致，就使用现有的类型化助手安装流程自动更新；同一个旧版本失败后本次运行不再反复弹窗，错误会显示出来，可用原有按钮手动重试。更新器本身仍只替换 App，Worker 的变更由重启后的 App 发起。开发包不会自动替换已安装的 Worker。

新增回归测试覆盖旧 Worker 的原始按下/抬起到点击的转换、版本不一致只自动尝试一次，以及持续等待回包时新版通道的点击发送仍能在 0.5 秒内执行。CI 的界面门禁需要真实 Aqua 会话和辅助功能授权，不能在托管 runner 上执行；它的结果不等于真实桌面点击验收。
