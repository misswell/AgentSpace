# 0.1.38 — 指针接管、二进制输入通道、光标离开视频：桌面第一次真的跟手（要按两下）

「检查更新」会把桌面查看器的这一半装上；但**鼠标怎么发出去、光标由谁绘制、帧率怎么变**全在 worker 里，所以要按「重新安装助手…」之后，下面这些才会真的发生在你手上。

（`0.1.37` 只是一个版本号提交，没有发布过，也没有产品改动；这一版从 `0.1.36` 直接过来。）

## 你报的「不如 RustDesk / Parallels 跟手」，根因不是输入通道

先量了一件事：桌面查看器每发一个鼠标事件，都要**开一个 socket、编码 JSON、等 worker 回包**。在这台机器上实测 p95 **0.597 ms**（旧版测量 3.98 ms）——这个数字在 5 FPS 下完全看不出来，在 60 FPS 下就很明显。

但真正的元凶是另一个：**默认帧率是 5 FPS，而 Agent 的光标是画在视频画面里的**（`showsCursor`）。也就是说远端光标永远不可能比最新一帧更新——最坏 200 ms 的延迟。这不是优化输入通道能解决的，得把光标从视频里拿出来。

## 这一版做了什么

**一条常驻的二进制输入通道。** 每个账号一个 `input.sock`，桌面查看器和所有 Fusion 窗口共用同一条连接，定长二进制包，鼠标移动发出去就不等回执。用这棵树的 worker 实测：同一条 socket 连发 **500** 个包，**p50 0.221 ms / p95 0.255 ms / p99 0.276 ms**。安全模型没有跟着提速一起松：对端 uid、token、账号、协议版本，以及**每一个包**都重新问一遍会话状态；agent 会话一旦变成物理控制台，立刻拒绝。

**指针接管（Pointer Capture）。** 鼠标进入 Agent 桌面即接管（默认 `Auto`），离开就交还；Fusion 窗口仍然是「按下才接管」，因为你的窗口就在它周围。`Control-Option` 或 `Control-Command-G` 可以随时手动交还。

**隐藏本地光标用的是 cursor rect，不是 `NSCursor.hide()`。** 这个区别很要紧：cursor rect 万一漏了重置，你看到的是**正常光标**；而 `NSCursor.hide()` 是进程级计数，漏一次反差就是整台 Mac 没有鼠标指针。

**光标离开视频。** worker 通过输入通道单独发布光标位置和形状（只用公开 AppKit，不碰 CGS 私有 API），查看器本地乐观绘制；只有在 worker **实测**证明它能读到本会话光标之后，采集才停止把光标画进画面。

**默认 30 FPS，按住鼠标期间自动 60 FPS**，而且是原地改（新的 `frame.setFPS` 走 `SCStream.updateConfiguration`），不会为了改一个数字重连、重建共享内存、重启解码器。

**双击仍然是双击。** 按下事件现在带着 `NSEvent.clickCount` 一起发，远端窗口服务器才知道第二次按是双击的第二下。

**修掉 §328 留下的那个未关闭问题**：窗口匹配不再要求「标题完全相等 + 位置误差 5 点以内」，改成打分；指针输入和窗口置前用「明显最佳」即可，而**关闭、最小化、改尺寸仍然严格要求唯一匹配**——点错窗口是误点，关错窗口没有撤销。

## 两个只有跑起来才会发现的缺陷

单元测试全绿也发现不了它们，是对着真 worker 连发才暴露的：

1. **拒绝回执把 worker 自己堵死了。** 在控制台会话里连发 500 个移动，每个都回一条拒绝，结果 worker 把自己的 socket 缓冲区写满，第 **196** 个包时连接因 send timeout 断开。现在重复的拒绝会按间隔采样，**但第一次拒绝、以及拒绝原因发生变化时一定发**——客户端永远不会丢掉「会话开始拒绝我了」这个信息。
2. **第二条连接连上了却永远收不到包。** 连接跑在串行队列上，第一条连接的 `read` 会一直阻塞到窗口关闭，第二条就永远排在后面。现在每条连接独立阻塞读。

两个都补了测试钉住。

## 这一版没有证明的

- **没有在真机上看过画面。** 这台机器上没有已连接的 agent 账号，控制台也是锁屏状态，所以窗口标题栏拖动、8 个边缘缩放手感、Fusion 实机、worker 重启与快速用户切换后的光标恢复**都没有实测**。上面写的延迟数字是**写包**的耗时，不是屏幕像素延迟。
- 光标形状通道是否可用，取决于 worker 在自己会话里能不能读到光标——这是运行时测量，不是假设；测不出来就继续用画面里的光标，不会出现「一个光标都没有」。
- CPU / RSS 没有测量。

## 装法

1. 在 AgentSpace 里「检查更新」→ 装上 0.1.38 的 App。
2. 按「重新安装助手…」→ 让 worker 也变成 0.1.38。**不做这一步，鼠标不会跟手**，因为上面绝大部分都在 worker 里。
