# 0.1.94 — 只有宣传片变了，不更新也可以

**这一版没有 App 行为变化，不更新也可以；如果你选择更新，先用一次
「重新安装助手…」对齐版本。** 除了版本号，0.1.94 的 App 与 0.1.93 没有区别；
版本号前进只是因为仓库里的营销素材换了。已经装好 0.1.93 的话，不必为这次更新。

**换掉的宣传片。** `marketing/promo/` 现在是 45 秒、八幕、中英双语的成片，
两种画幅：1920×1080 和 1080×1920，每种语言一版，共四支。八幕依次是：开场 →
一台 Mac 两个桌面 → 不是虚拟机、是真实会话 → 连接应用 → 多代理并行 → 安全内建
（在物理控制台拒绝注入）→ 24 个客户端 / 22 个 MCP 工具 → 结尾 CTA。画面仍然
没有二维码，下载地址只以文字 `github.com/misswell/AgentSpace` 出现。

**配乐是原创的、可复现的。** `audio.mjs` 用 80 BPM 的 Am9 → Fmaj9 → Cmaj9 → G6
和声循环，加法合成 pad、低音、拨弦琶音与合成鼓组，经混响、乒乓延迟和软限幅后
归一化；不含采样，也不含 `Math.random`/`Date.now`，同一份源码每次生成同一段
45.000 秒、48 kHz 立体声 PCM。`render.mjs` 现在可以在逐帧截图后直接调用 ffmpeg
混流（H.264 High、yuv420p、CRF 18、faststart、AAC 192 kbps）。

**怎么复现。** 见 `marketing/promo/README.md`：

```sh
node audio.mjs --out /tmp/agentspace-promo.wav
node render.mjs --lang zh --audio /tmp/agentspace-promo.wav \
  --mp4 AgentSpace-Promo-1080p.mp4
```

竖版加 `--vertical`，英文把 `--lang en`。四支成片是本地构建产物
（`marketing/promo/*.mp4` 本来就不入库），仓库里保存的是源工程。

**没改的。** App、privileged helper、Worker、协议版本、MCP 工具和登录流程的
行为全部未动。助手版本随 App 前进，所以如果选择更新，第一次使用前要重新安装
一次助手对齐版本——这只是版本对齐，没有任何新行为。
