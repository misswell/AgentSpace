# 0.1.41 — 单独 App 窗口跟随拖动调整实际大小

**在 AgentSpace 中按「检查更新」安装这一版，并在 macOS 提示时授权更新 Worker。** 这项功能需要 App 和 Worker 都是 0.1.41；应用会自动发现版本不一致并尝试更新 Worker。

「单独融合 App」窗口现在按 Agent 账号中原始 App 窗口的大小打开，最多占用主系统当前显示器的可见区域。拖动代理窗口边缘时，Agent 账号里的原始 App 窗口会同步调整宽高；代理会采用 App 实际允许的尺寸，避免画面留黑边或点击位置偏移。采集分辨率按主系统显示器的像素密度请求，缩放后画面会随窗口重新配置。

打开 App 或激活功能不再自动弹出新的本地代理窗口。「打开应用」现在先列出 Agent 桌面的窗口，只有点对应的「打开窗口」才创建代理；在 Agent 桌面启动 App 也只负责启动，显示窗口需另外选择。

「打开桌面」现在让窗口里的**桌面画面区域**保持 Agent 内屏的长宽比；拖动外框时，宽高一起调整，画面完整铺满，不出现上下黑边，也不裁切桌面。标题栏和控制区高度另行计算。AgentUse 当前仅提供 1920×1080 一种系统显示模式；测试发现临时虚拟屏也会加入主系统显示器列表，因此这一版不创建虚拟屏，也不改变主系统显示布局。

本地 Swift 测试和 AgentUse 独立会话中的界面检查通过。真实单独窗口的拖动验收仍需在安装新版 Worker 后完成；CI 的托管 macOS runner 不具备该 Aqua 会话与辅助功能授权。
