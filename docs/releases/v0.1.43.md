# 0.1.43 — 桌面最低 2×，修复窗口按钮点击

「打开桌面」现在选择 Agent 会话中真实的 2× 或更高倍率屏幕。当前 AgentUse 会话使用 1512×982 点、3024×1964 实际像素的屏幕；采集、窗口比例、鼠标点击与光标位置都对应这块屏幕。没有可用的 2× 屏幕时，窗口会明确提示，不会把 1× 画面放大后当作 Retina。

修复点击 App 左上角关闭、缩小按钮只高亮却不执行的问题。此前鼠标松开时会额外发送一次零位移或微小位移的拖动事件；现在原地点击只发送按下和松开，真实拖动仍会连续发送位移。

指定第二块屏幕截图时，截图回复中的实际像素和倍率也取自该屏幕，不再误报主屏的 1× 数据。

**更新后需让 Worker 同步到 0.1.43。** App 会在前台检测并尝试更新版本不一致的 Worker；macOS 可能要求管理员授权。若自动更新没有完成，可在 App 中使用「重新安装助手…」。原本位于 1× 主屏上的 App 窗口不会自动搬到 2× 屏幕，需在 Agent 会话中移动或重新打开。此更改不会新增虚拟显示器或改变主系统的屏幕排列。

本地单元测试、MCP、更新器与 Agent 会话界面检查通过。正式包由 CI 签名、公证并发布。
