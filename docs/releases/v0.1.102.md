# AgentSpace 0.1.102

**如果之前更新到 0.1.101 时已经允许过「重新安装助手」和 Worker 更新,这一版不需要任何额外操作。** 没有走过那一步的,更新后仍请允许一次(那是 0.1.101 修复的一部分)。

---

## 这一版带来了什么

**端口映射的整个使用体验按普通用户重新设计:每个状态都有说明,每个问题都告诉你怎么修,重试自动进行且可以手动触发。**

- **前提状态区**:卡片顶部只有在有问题时才出现提示条——配置目录未就绪、Worker 版本过旧、Worker 离线——每条都配一句人话和一个「更新 Worker」按钮(直接走应用已有的一次性更新流程);一切正常时完全隐藏。
- **全部报错中文化、逐条对应解决办法**:不再出现英文产品消息或系统原文。例如:端口没在监听(「先在子账号桌面里启动服务,或从『正在监听』一排点选」)、端口绑在外部网卡(「请在子账号里改为监听 127.0.0.1」)、外部端口被占(「换一个端口」)、配置目录未就绪(「一次 Worker 更新即可创建」)……共十余种,各有专属文案。
- **添加前先验证**:现在界面添加映射前会先向子账号的 Worker 确认端口归属(与命令行一致的防呆),不再允许把没在监听的端口加进列表。
- **每个地址一键可用**:每条映射和固定地址行都有「复制」和「**在浏览器打开**」按钮——后者就是最直接的「能不能用」测试;状态用绿色/橙色徽章标示。
- **成功即反馈**:添加成功显示绿色「已映射:127.0.0.1:xxxx —— 现在就可以访问」,带复制按钮。
- **重试看得见**:列表/地址每 3 秒自动校正,助手失败每 20 秒自动重试(文案注明),固定地址失败时另有「重试」按钮可立即再试。
- **空状态有指引**:没有服务在监听时,提示「在子账号桌面上启动你的服务,端口几秒内就会出现在这里」。

## 其他

- 无协议、无 Worker 方法、无注册表变化;固定地址功能仍默认关闭。
- 规则层抽为单一纯函数并有对抗测试(`PortMapRulesTests`)。
