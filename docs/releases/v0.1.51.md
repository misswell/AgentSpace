# 0.1.51 — 接管时指针持续跟随，不再五秒后冻结

通过「检查更新」更新 App 即可，无需任何设置更改。本次修复只在 App 内的指针投递路径上，Worker 无需变动。

- **修复「接管了，但指针不跟随，点击仍然有效」**：0.1.49 加入「自动」「接管」两种模式后，指针进入画面会取得一次「人工租约」（它让自动化暂停、也让移动包生效），但这份租约只有 5 秒，而且**只有显式续租才会延长**——夹在中间的纯移动从不续租。于是接管约 5 秒之后，每个移动包都被 Worker 当作「无人接管时的扫过」静默丢弃：指针不再跟随；点击不受租约限制，所以照常触发；按住拖动会续租，所以它时好时坏。现在被接管的画面在移动时会按拖动同样的频率主动续租，指针持续跟随；按下本身也会立刻取得租约。
- **未接管的画面不受影响**：只是把指针从画面（或 Fusion 代理窗口）上划过时，悬停仍然不会延长租约，不会无故把自动化按停。

验证结果记录于 `docs/validation.md` §343；实际手感仍以人工验收为准。
