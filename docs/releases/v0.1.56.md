# 0.1.56 — 拖动窗口不再闪断；窗口边缘出现调整大小光标

**这次 App 和 Worker 都有改动：先「检查更新」，再按一次「重新安装助手…」，两步都做完才是完整体验。** 只更新 App 时，桌面拖动已经不闪断；窗口边缘的调整大小光标要等 Worker 换上之后才出现。

- **拖动 Desktop Viewer 窗口边缘不再黑闪。** 此前每次窗口布局都会按窗口像素重算采集请求，尺寸变化 ≥16 像素就关流重开——拖动过程中就是一次接一次的重连闪断，刚打开窗口时也会多一次。现在桌面流的采集尺寸在打开时定死（跟随「捕获宽度」档位，「原生」就是源显示器的全部像素），窗口缩放只由 GPU 缩放画面：拖小、拖大、进全屏、退全屏，全程不重开流、不黑屏，点击映射照常工作。
- **「缩放」菜单移除。** 画面始终完整适配窗口，这个菜单从来不能真正缩放画面，只是暗中改采集缓冲大小。按 0.1.52 的同一原则删掉不做事情的控件；清晰度由「捕获宽度」档位决定。单独融合（Fusion）窗口的跟随行为不变。
- **主窗口工具栏右上角新增「设置…」齿轮入口。** 设置窗口原来只能从应用菜单（⌘,）打开；现在工具栏最右侧就是齿轮，点开即设置窗口。这不违反 0.1.52 的去重原则——设置窗口不在页面里，这是新增去处，不是重复页面。
- **窗口边缘的调整大小光标回来了（需要「重新安装助手…」）。** macOS 的 resize 光标由系统私有绘制，公开 API 读回来是空图，所以隐藏远端光标后，把鼠标移到 Agent 桌面里的窗口边缘时没有任何箭头。现在 Worker 在读取失败时按指针位置和窗口边框几何合成对应的箭头（左右、上下、四角斜向），走原有光标通道发布——协议、权限、查看端都没有变。
- **鼠标模式说明。** 模式仍是 Auto / Capture / Click to Capture：Auto 稳态下就是「接管 + 双侧隐藏」——本地光标在画面上隐藏、远端光标停止画入视频、由查看器本地绘制并跟随，移动是绝对坐标映射。这与 RustDesk「隐藏远端光标」的默认体验一致，不需要新模式。

验证记录见 `docs/validation.md` §348。合成箭头与人手拖动的实时手感仍欠一次本人的确认（§348 第 1032、1035 行如实标注）。
