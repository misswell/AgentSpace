# 0.1.70 — 显示质量互相切换后画面不再卡住

先「检查更新」，然后重新打开桌面或应用窗口。本次修复在 App 端，无需重装助手。

原生、均衡、性能互相切换时，新的画面流已经建立，但 SwiftUI 复用了仍绑定旧画面流的显示组件。旧流停止后，画面停在原处，新流没有渲染回调。

现在显示组件的生命周期与画面流一致：切换质量或重新连接会绑定新流，并使用独立渲染器，旧流退出不会清空新画面；同一流内的布局、鼠标模式等更新保持原组件。桌面与打开应用共用该修复。

实际 SwiftUI/AppKit 回归覆盖各档位连续切换；AgentUse 后台会话的真实帧链路验证了六次切换后均有画面成功应用。证据见 `docs/validation.md` §370。
