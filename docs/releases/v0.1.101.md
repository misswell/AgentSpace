## 这一版修了什么

**修复：首次使用端口映射 / 固定地址 / API 开关时报「你没有权限将文件"Network"保存到文件夹"AgentSpace"中」。**

原因是产品缺陷，不是你操作的问题：共享配置目录
`/Library/Application Support/AgentSpace/Network` 从来没有任何代码创建过——它的父目录由 root 持有，普通用户的第一次写入（保存端口映射、打开固定地址开关、启用 API）必然被拒。这个缺陷从 0.1.98 就存在，只是端口映射的开关让它第一次变得随处可见。

修复方式：特权助手现在会在**每次安装/更新 Worker 时**创建这个目录并移交给你的主用户（与它一直管理 `Spaces`/`Logs`/`Worktrees` 的方式完全相同）。所以更新到本版 → 允许助手更新 → 允许 Worker 更新，目录即就绪，之后：

- 「端口映射」卡片里添加映射（`8080 → 28080`）、
- 打开「给该账号一个固定地址」、
- 设置页启用 Remote API，

全部正常写入。在目录就绪之前，这些操作会显示一句明确的提示（「配置目录尚未就绪，请更新并允许一次助手与 Worker 更新」），不再是看不懂的系统原文。
