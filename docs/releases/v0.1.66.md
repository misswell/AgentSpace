# 0.1.66 — 接管隐藏鼠标：关闭真实绘制层和被读帧阻塞的控制指令

先「检查更新」，重新打开桌面窗口。Worker 已是 0.1.63 或以上时无需重装助手；更旧的 Worker 仍需「重新安装助手…」。

「接管隐藏鼠标」只显示你自己的外部鼠标，隐藏画面内部的鼠标。本次修复两个已通过失败测试复现的问题：

- 关闭画面内鼠标的指令与持续读帧共用串行队列，读帧期间指令一直无法执行。控制指令现在独立发送，FPS 调整也不再被读帧阻塞。
- 隐藏开关只改变代理状态，没有控制实际鼠标图层；数据包、预测移动和布局会继续显示它。现在真实图层有持续有效的绘制开关，切换模式立即隐藏，后续移动也不会重新显示。

隐藏模式从打开窗口开始就关闭内嵌鼠标，不依赖鼠标形状通道；切换模式、重连和 Fusion 捕获重启均重新应用这一要求。其他模式保留各自的鼠标策略。

验证证据见 `docs/validation.md` §366。新增回归测试直接覆盖真实 CALayer 和阻塞读帧时的控制调度。
