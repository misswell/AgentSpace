# 0.1.59 — 「接管隐藏鼠标」成为看得见的默认模式；窗口空闲休眠；ZCode、Kimi Code、小米 MiMo 一条命令接入

**这次不涉及助手（worker/helper）改动：通过「检查更新」更新即可，不需要「重新安装助手…」。**

## 鼠标：你指出的没错

上一轮我说「Auto 稳态下等价于接管隐藏」，于是没有把它做成一个看得见的模式——结果你在拾取器里根本找不到它，而 Auto 默认「指针停稳 0.2 秒后才同步悬停」，连续移动鼠标时远端光标不动，看起来就是「鼠标没有效果」。要的模式就得是模式本身。

- **鼠标控制默认就是「接管隐藏鼠标」**：指针一进入 Agent 桌面立即接管——两边只有一个光标（本地光标在画面上隐藏、远端光标停止画入视频、由查看器本地绘制），移动、点击、拖动、滚轮在移动中实时跟随，不再等停顿。这与 RustDesk / Parallels 的默认体验一致。
- **拾取器三项清晰可辨**：接管隐藏鼠标（默认）／自动（停顿后才同步悬停，旧行为可显式选回）／点击后接管。旧存值自动保留其行为：存过「接管(Capture)」的自动变为「接管隐藏鼠标」，存过「自动」的保持「自动」，存过「点击后接管」的不变。
- Control-Option 或 Control-Command-G 随时交还控制权，与之前一致。

## 新增：窗口空闲休眠

Desktop Viewer 常开一整天时，画面流即使闲到 5 FPS 也一直占着采集、共享内存和 socket。现在窗口会在**你**空闲达到设定时长后自动休眠：

- 时长在查看器「详情」弹层里选：**5／15／30（默认）／60 分钟／从不**。
- 休眠 = 画面流真实停止（采集、共享内存、socket 全部释放），窗口显示「画面已休眠 · 点击唤醒」；点一下即恢复实时。
- 空闲时钟只认你的手（手势、拖动、按键），不认桌面忙不忙——Agent 忙一整天正是值得睡过去的场景。休眠期间窗口不再吞键盘（不会盲打进 Agent 会话）。

## 新增：`agentspace integrate` 支持三个新客户端

让别的 agent 在 AgentSpace 里做测试，现在一条命令可以配到六个客户端。三个新增目标的配置位置和格式都是从本机**实际安装**的客户端实测的，不是照文档猜的：

```bash
agentspace integrate zcode --install   # ~/.zcode/cli/config.json（嵌套 mcp.servers，严格 schema）
agentspace integrate kimi --install    # ~/.kimi-code/mcp.json（与 Claude 同形）
agentspace integrate mimo --install    # ~/.config/mimocode/mimocode.jsonc（与 OpenCode 同形）
```

（已有目标不变：`claude` / `codex` / `opencode`；图形界面账户页的「安装 MCP 到…」菜单同样列出六个客户端。）

- 写入前自动备份为 `<配置文件>.agentspace.bak`；只写 `agentspace` 一个条目，文件里其他内容（包括 MiMo 的 `$schema`、ZCode 的 `plugins`）原样保留，重复执行安全。
- 小提示：如果终端里敲 `agentspace` 提示 `command not found`，先加一个别名再执行（CLI 随 App 一起安装）：
  ```bash
  echo 'alias agentspace=/Applications/AgentSpace.app/Contents/Helpers/agentspace' >> ~/.zshrc && source ~/.zshrc
  ```

验证记录见 `docs/validation.md` §351–353。鼠标手感（连续移动下的跟随贴合度）仍以你的手为准。
