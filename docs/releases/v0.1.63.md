# 0.1.63 — 状态条并入顶栏：桌面窗口少一排

**这次改了 App 和 Worker：先「检查更新」，再「重新安装助手…」——两步都要按。**

你问「状态栏可以移到顶栏吗」——可以。桌面窗口原本有两排：标题栏（AgentUse Desktop）+ 状态控制条（● 名称 ／ 重连、暂停、画质、帧率、鼠标、截图、信息、关闭）。现在两排合一：

- 状态条**就是**标题栏——交通灯落在状态条左端，「AgentUse Desktop」标题保留给任务控制与 ⌘Tab 但不再画出来，省下的一整排高度全部给了桌面画面。
- 状态条空白处可拖动窗口，各控件照常点击；窗口标题里的「AgentUse Desktop」在最小化/切换器里仍可见。
- 「详情」里的窗口空闲休眠设置不受影响。

验证记录见 `docs/validation.md` §361。合并后的顶栏观感（交通灯间距、拖动手感）以你的眼和手为准。

- **修复「接管隐藏鼠标仍未生效」（第二次报告）**：这一次找到的根因在 Worker 里——光标形状「已证明可读」后的能力宣告被派发到主队列，而 Worker 主线程终生停在 `accept()` 等待连接，这条回调**永远不会执行**，于是给 App 的能力表里从来没有 `cursorShapes`，整条隐藏/接管光标链路（隐藏本地光标、停画内嵌光标、绘制远端光标）从诞生起从未启动。现改为在采样队列上直接宣告（与同文件里的光标发送同一模式）。红绿证据：同一探针对准现装的 0.1.62 Worker——握手后第二包永不到来、能力表无 `cursorShapes`；对准本树构建的隔离 Worker——第二包按时到达并带上 `cursorShapes`。

验证记录见 `docs/validation.md` 与本节说明同上。
