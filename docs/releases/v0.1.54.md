# 0.1.54 — 连接完成不再「毕业即失明」：每一步都告诉你去哪、带你过去

通过「检查更新」更新 App 即可。本次改动只在 App 的管理界面与连接流程；协议未动。**已经连接成功的账号不受影响**——如果你正停在 0.1.53 的向导里:直接点「取消」关闭,到侧栏选中账号,在「权限与授权」卡片里点「打开授权向导」即可继续。

## 这次解决什么

上一版修好了「连不上」;这一版修好「连上之后没人告诉你下一步」。实测链条上的三处断点:

1. **连接成功后,向导把人放回一个无事可做的界面**。完成页现在直接说「已连接,还剩一步:授权」,并给出「开始授权…」按钮——关闭向导、自动选中新账号、打开授权向导(授权必须由你在账号自己的会话里批准,这是 macOS 的安全设计,App 无法代劳,但 App 可以把你带到正确的面板面前)。不需要首登的账号不再看到首登说明;需要首登的仍会看到。
2. **账号页没有把「还差什么」放在眼前**。worker 在运行而授权缺失时,页面顶部现在有一条醒目横幅:「还差 N 项授权,桌面还不能使用」+「开始授权…」按钮。授权齐了横幅自动消失。
3. **刚连接的账号永远显示「休眠」**。首次启动的新 worker 超过了连接时 7 秒的就绪探测预算,记录被存成 offline,而之后没有任何机制推进它——侧栏在 worker 正常应答时仍显示「休眠」。现在:探测预算提高到 20 秒;每次刷新都会用活体快照校准记录(只推进「等待中」的两种状态,磁盘只在有变化时写)。CLI 的 `accounts` 同步受益。

## 面向第一次使用的人

现在的完整流程,每一步的下一步都在界面上:新建 Agent → 连接账号 → 完成页「开始授权…」→ 授权向导(三项授权,每项一个直达系统设置的按钮)→ 批准后回来刷新 → 就绪、打开桌面。不再有任何一步需要猜。

验证记录见 `docs/validation.md` §346。
