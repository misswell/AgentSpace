# 0.1.64 — 「接管隐藏鼠标」改为隐藏画面内的光标：你自己的光标永远可见

先「检查更新」；如果你还没为重装过助手（0.1.63 的修复在 Worker 里），再按一次「重新安装助手…」。

你指出的对：「接管隐藏鼠标」要隐藏的是**画面里那个（内部的）光标**，不是你自己手上的光标——隐藏自己的光标会让指针变成跟随远端位置的滞后光标，延迟感很大，这是错的。修正后的行为：

- **接管隐藏鼠标**：指针进入画面即取得控制、持续跟随；**你自己的光标始终可见、零延迟**；画面里不再出现任何光标（Worker 视频里内嵌的那个已经关掉，本地叠加的远端光标也不再画）——画面干净，指针就是你自己的手。
- **接管**：同样进入即控制、持续跟随，但**画面上会显示远端（内部）光标**，你自己的光标也在；需要看 Agent 会话光标位置时用它。
- **自动**与**点击后接管**行为不变。

验证记录见 `docs/validation.md` §364（含 8 条模式判别测试）。上一版 0.1.63 修好了「内部光标根本关不掉」的三处断点（能力宣告、内嵌光标开关、sprite 门控），这一版把语义摆正：内与外的光标各归其位。
